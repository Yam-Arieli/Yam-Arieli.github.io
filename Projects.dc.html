NeuronLens

What is this network actually doing, layer by layer?

Hand it a trained PyTorch model and a labelled dataset; it returns a single self-contained HTML file where you can watch activations flow, filter by any metadata condition, and hover a neuron to trace its influence forward through every downstream layer.

  • Neurons are permuted within each layer to minimise weighted edge crossings, so neurons that fire together sit together.
  • Two-filter compare mode blends blue/red per neuron to show where two cohorts diverge.
  • Output ships as one file with all data inlined: no server, no build step, opens anywhere.

PyTorch · forward hooks · canvas renderer · zero-dependency output

Survival of the Flattest

Does evolution pick the fittest sequence, or the most mutation-proof one?

A pipeline that simulates the fitness landscape of yeast promoters: a 1D-CNN oracle predicts expression from 110bp of DNA, a Gaussian optimality curve maps expression to fitness, and a rectified-flatness metric scores how fragile each sequence is to mutation.

  • The rarest promoter sits exactly at the Pareto knee: maximum robustness bought without giving up peak fitness.
  • The most common promoter sits deep inside a super-flat plateau, surrounded by equally fit neighbours.
  • Fragility scored over all 240 one-mutation neighbours, counting only deleterious moves, a rectified alternative to the Hessian trace.

PyTorch 1D-CNN · Pareto optimisation · built in a lab hackathon

TrainStream

How do you train on 10M cells × 20K genes without distributed infrastructure?

A streaming-coreset loop: merge each incoming chunk with a small retained buffer, train, then use per-sample training dynamics to decide which samples earn their place in the buffer. The model sees all the data once; the most informative samples keep influencing training after their chunk is gone.

Memory cost is 2k + m + model, independent of total dataset size.

  • Five selection strategies: AUM margin, mean confidence, weighted-quantile sampling, forgetting events, and a random baseline to prove they beat it.
  • Two independent staleness guards stop early chunks from colonising the buffer: a per-chunk share cap and geometric confidence decay.
  • Every retained sample carries its provenance, so you can audit which chunks the final coreset actually came from.

PyTorch · scanpy / AnnData · pip-installable · MIT

Manager–Worker Agentic QA Pipeline

Can a small model learn to break a hard question into easy ones?

Fine-tuned Flan-T5 as a manager that iteratively decomposes complex queries into sub-questions a RoBERTa worker can answer, then recombines the answers. The interesting half was the evaluation: an STS-based framework that scores semantic agreement rather than exact match, so the decomposed pipeline could be compared honestly against single-model baselines.

  • Manager and worker are separate, swappable models: the decomposition strategy is learned, not prompted.
  • Semantic-similarity scoring avoids the exact-match trap that flatters extractive baselines.

Yad2 Real-Estate Scraper

What does the Israeli housing market look like if you measure it yourself?

A scraper that turns live marketplace listings into a clean DataFrame and an Excel export, feeding an interactive Looker dashboard anyone can explore. The most-used thing I've published, and the reason I ended up writing about the techniques behind it.

  • End-to-end and public: scrape → structure → publish, with the dashboard live for anyone to poke at.
  • Generalised past its first target: a reusable scraper module rather than one bespoke script.
