# Yam Arieli — Portfolio

Static portfolio site, originally produced in Claude Design. Live at
**https://yam-arieli.github.io/** — deployed automatically by GitHub Actions on every push
to `main`.

## The repo is public

GitHub Free cannot serve Pages from a private repo, so this repo is public. Never commit
`uploads/`, `scraps/`, or any personal document (CV drafts, cover letters, unpublished
photos). They are gitignored — keep it that way.

**No CV/résumé in the repo.** The CV PDF was removed because it carries a personal phone
number. The "Résumé" button in each page's nav is deliberately inert — an `<a>` with no
`href`, styled exactly as before — and the footer shows plain "Résumé" text instead of a
download link. Do not re-add a CV file or wire those back up unless asked.

### The standalone simulator page

`Simulator.dc.html` → **https://yam-arieli.github.io/Simulator.html**. It is the version
built to be *presented* — thesis defence, talks: open it full-screen, screen-record it, or
link it from a slide, with no nav to navigate and no card to click open. It is not linked
from the nav; only the Education page is (and this page links back).

It is **built up one layer at a time**, because a panel that explains itself has to be shown
on its own first. It opens on the two vessels and their drifting cells and nothing else;
four toggles — buttons, or keys `1`–`4` — reveal the cytokine particles, the
squareness–redness plot, the projection arrows with their dashed guides, and the Δ verdict
panel, in that order (`space` = pause/play, `i` = inject, `r` = reset). Reveal `3` pulls `2`
in with it and hiding `2` hides `3`, so a projection is never switched on behind a hidden
plot. `renderVals` recomputes the grid from those flags, so a hidden panel gives its column
back instead of leaving a hole. Hiding the cytokines is **drawing only** — `stepVessel` is
untouched, so they still move, bind and cascade while invisible, which is the whole point of
that reveal.

Its relationship to the `data-detail="simulator"` panel in `Education.dc.html`:

- The **physics is shared and must stay in sync** — `genVessel`, `addCyto`, `stepVessel`,
  `meansOf` and `projections` are character-identical in both files, as are the `popup*`
  method and binding names. Change one, change the other.
- The **presentation deliberately differs** and should not be copied back: the staged
  reveal and its control bar, the vessel colours (`--sim-vessel-a` / `--sim-vessel-b` — the
  dark parent of each vessel's own projection ink, replacing the cyan/magenta arrows, which
  collided with the cell colours), projections drawn last and at half thickness so they sit
  in front, canvases backed at 2× the simulation world (vessels 560 for a 280 world, plot
  840), and panels capped in `vh` so each reveal state fits one projected screen.

## Edit loop

```bash
# 1. edit the text in the relevant *.dc.html
# 2. rebuild
bash build.sh
# 3. preview — must be over http://, not file://
python3 -m http.server 8000 -d dist
# 4. ship
git commit -am "…" && git push      # Actions deploys within ~1 min
```

`build.sh` copies the five pages into `dist/`, rewriting internal `X.dc.html` links to
`X.html`, and adds `.nojekyll` (without it Jekyll strips `_ds/` and the site loses all
styling).

## Runtime notes

The pages are not self-contained: `support.js` lazily fetches React 18 and Babel from
unpkg, and `styles.css` imports Source Serif 4 from Google Fonts. The site therefore needs
network access to render, and must be served over `http://` — opening a file directly will
not work.

Page logic lives in the `<script type="text/x-dc" data-dc-script>` block at the bottom of
each page, as a `class Component extends DCLogic` (React component semantics: `state`,
refs, `componentDidMount`). `data-props` on that tag declares the editable props.

## Design system

Take every color, font size, spacing and radius from the CSS variables in
`_ds/broadsheet-*/styles.css` — `var(--color-*)`, `var(--font-*)`, `var(--space-*)`,
`var(--radius-*)`, `var(--shadow-*)`. Do not hardcode hex values or px. Read
`_ds/broadsheet-*/readme.md` before making visual changes; it documents the intent
(newsprint serif on paper white, cyan/magenta as spot color, hierarchy from scale and
whitespace rather than boxes and dividers).

One deliberate exception: the Education simulator needs two inks the three-ink system does
not have, for the projection arrows that carry the thesis argument. They are declared once
as `--sim-green` / `--sim-orange` in the `<style>` block of `Education.dc.html` and used
only there. Add page-level tokens the same way rather than hardcoding a hex inline.
